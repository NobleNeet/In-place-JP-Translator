Debug (console)

On the page (F12 → Console), filter by [PLaMoTranslate] and run:

__plamo.getState()        // counters of the last run (incl. requests used)
__plamo.getBatchPlan()      // how the next run packs segments into API requests
__plamo.getApplied()      // text nodes rewritten so far (original → Japanese)
__plamo.dumpLogs()        // last log records, including trace level
__plamo.backgroundLogs()  // the worker's own logs, printed here
__plamo.getPending()      // what would be translated now
__plamo.pingBackground()  // is the worker alive?

Worker console: chrome://extensions (or vivaldi://extensions) → Service Worker → Console → __PLAMO__.background.getDiagnostics().
